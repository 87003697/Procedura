# 依赖排查

## 2026-09-02

- 现象：在未安装依赖的 worktree 中运行 `bun run procedura --help`，Bun 报 `Cannot find module '@harness/template'`。
- 原因：`package.json` 的 `@harness/template: file:./vendor/harness`、`bun.lock` 和 `vendor/harness` 均正常；实际缺少当前 worktree 的 `node_modules`。主工作区安装依赖不会被其他 worktree 共享。
- 修复：在目标 worktree 执行 `bun install --frozen-lockfile`（不支持时使用 `bun install`）。安装后 `@harness/template` 可解析，`bun run procedura --help` 正常启动。
- 另一个环境提示：若未设置 `OPENSCAD_PATH`，Procedura 可能提示缺少 Manifold-capable OpenSCAD。系统安装位于 `/opt/homebrew/bin/openscad`，版本 `2026.08.29`；设置 `OPENSCAD_PATH=/opt/homebrew/bin/openscad` 后启动探测正常。

> 分支 `main` 落后 `origin/main` 与依赖缺失无关；同步分支应单独处理，避免与依赖修复混在一起。
